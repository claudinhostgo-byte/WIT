How we do it

Cloud Adoption Framework, in waves.

Landing zone first, then migrations in small waves to learn fast, with costs and security under control from the start. Based on Microsoft's Cloud Adoption Framework and Well-Architected Framework.

  1. We define the why and the what for: business outcomes, not just servers.

    Cloud Adoption Framework · Business case approved

    What we do

    • Motivations and expected outcomes: costs, agility, security, data center exit.
    • Business case and cost model (TCO) on Azure.
    • Initial inventory of workloads and dependencies.
    • Data and AI use cases the cloud enables.

    What you get

    • Adoption strategy and business case.
    • Workload inventory.
    • First candidate wave.

    AIAI in this phase

    Automated discovery and classification of workloads and dependencies.

  2. A wave plan, with the first one small enough to learn fast.

    Cloud Adoption Framework · Wave plan approved

    What we do

    • Assessment of each workload: migrate, modernize or replace.
    • Migration waves ordered by dependency and risk.
    • Team readiness: roles, skills and operating model.
    • FinOps from the start: budget and cost controls.

    What you get

    • Wave-based adoption plan.
    • Operating model and roles.
    • Budget and cost controls.

    AIAI in this phase

    Sizing and cost recommendations per workload.

  3. We build the landing zone: the secure, governed foundation where everything lands.

    Cloud Adoption Framework · Landing zone ready

    What we do

    • Azure landing zone: subscriptions, network, identity and policies.
    • Baseline security: Microsoft Entra ID, Microsoft Defender for Cloud and backups.
    • Hybrid connectivity and data residency in Azure Chile Central.
    • Infrastructure as code and deployment pipelines.

    What you get

    • Operational landing zone.
    • Active security policies and controls.
    • Reusable infrastructure templates.

    AIAI in this phase

    Assisted configuration review against Azure recommendations.

  4. We migrate and modernize in small waves.

    Cloud Adoption Framework · Wave migrated and validated

    What we do

    • Migration with Azure Migrate and testing of each wave.
    • Modernization where it adds value: PaaS, containers, Azure Virtual Desktop or Azure VMware Solution.
    • Planned cutover and validation with the business.
    • Cost optimization at the end of each wave.

    What you get

    • Migrated and validated workloads.
    • Cutover and rollback runbooks.
    • Cost report per wave.

    AIAI in this phase

    Anomaly detection and optimization recommendations during the migration.

  5. The cloud is governed, secured and operated every day.

    Cloud Adoption Framework · Cost and security review

    What we do

    • Governance: policies, tagging and cost control (FinOps).
    • Continuous security: posture, identities and compliance.
    • Operations: monitoring, backup, continuity and updates.
    • Periodic reviews with the Well-Architected Framework.

    What you get

    • Managed operations with service levels.
    • Cost, security and compliance reports.
    • Continuous improvement plan.

    AIAI in this phase

    Intelligent monitoring and operations agents on alerts and costs.

Phases based on Microsoft's Cloud Adoption Framework (Strategy, Plan, Ready, Adopt, Govern, Secure, Manage). Cloud Adoption Framework on Microsoft Learn ↗
